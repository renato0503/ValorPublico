Para o seu gabinete

O código é trocado por um token de longa duração no servidor e guardado em segredo do servidor (nunca no Firestore legível pelo cliente). Para trocar o código pelo token, o técnico do gabinete roda: 

cd backend
python scripts/conectar_conta.py --agente <id> --rede instagram --codigo <CODIGO>

A desconexão apaga o token e os dados brutos daquela rede — ver Exclusão de dados.
