1. Abra o Console no botão acima → Authentication → Templates → Redefinição de senha.
2. Cole o assunto e o HTML (o Console aceita HTML no corpo).
3. Confirme o “Nome público” em Configurações do projeto — é o %APP_NAME%.
4. Envie um teste.
